How ScamShield Works

Five independent analysis layers work together to catch scams from every angle.

01
🔤

NLP Text Analysis

Detects urgency language, impersonation tactics, OTP/credential requests, prize baits, fake authority claims, and social engineering patterns.

Urgency Detection OTP Tricks Impersonation Fear Tactics
02
🔗

URL / Domain Analysis

Identifies lookalike domains via Levenshtein distance, homoglyph substitutions, suspicious TLDs, IP-based URLs, URL shorteners, and phishing path patterns.

Lookalike Domains Homoglyphs Suspicious TLDs IP URLs
03
📷

QR Code Analysis

Decodes QR payloads in-browser, validates UPI VPAs, detects the notorious "scan to receive" trick, embedded phishing URLs, and suspicious transaction metadata.

UPI Validation Pay/Receive Trick Embedded URLs Amount Flags
04
🧠

Behavioural Context

Analyzes payment context: amount vs. stated purpose mismatches, payee name impersonation, advance-fee patterns, and high-value transaction flags.

Amount Mismatch Payee Patterns Advance Fee Context Analysis
05
⚖️

Risk Fusion Engine

Combines all signals using a weighted scoring model. Every signal contribution is fully transparent — you see exactly what triggered the warning and why.

Weighted Scoring Explainable AI Multi-signal Fusion 4-tier Risk
